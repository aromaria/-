# デイリーダッシュボード（/morning）

以下の6セクションを並列で調査し、結果をダッシュボード形式のHTMLアーティファクトとして公開する。

## 実行手順

### 1. メール（Gmail）
- Gmail MCP の `search_threads` で未読メールを取得（`is:unread`）
- 要返信・要対応のものを優先順位（高/中/低）付きでリストアップ
- スター付き（`is:starred`）は削除対象外として明示

### 2. 本日・明日の予定（Googleカレンダー）
- Google Calendar MCP の `list_calendars` で全カレンダーを取得（iCloud購読分含む）
- `list_events` で今日と明日の予定を全カレンダーから取得
- 時系列でまとめ、準備が必要なもの（資料・移動・持ち物など）があれば明記

### 3. 進行中の案件の進捗（Google Drive）
- Google Drive MCP の `search_files` で以下の案件ごとに最新ファイルを検索:
  - アロマリアAI Studio開発
  - アロマリア向けメール自動化システム（ReserveStock連携）
  - TKC会計システム
  - 縄文文化講演会
  - Notionガイド制作
  - 相続調停関連
- 更新・締切が近いものがあれば報告

### 4. 市況・投資関連ニュース
- WebSearch で以下を検索:
  - USD/JPY 為替レート
  - 日経平均・TOPIX
  - 主要な市場ニュース
- 簡潔に要約

### 5. 業界・関連ニュース
- WebSearch で以下を検索:
  - アロマテラピー業界の最新動向
  - AIツール活用の最新情報（Claude, ChatGPT, MCP等）
- 重要なものだけ報告

### 6. 不要メールの自動整理（Gmail）
- Gmail MCP で以下の条件をすべて満たすメールを検索:
  - `is:unread -is:starred older_than:30d category:promotions OR category:updates`
  - メルマガ・広告・キャンペーン系と判断できるもの
- **添付なし**: 確認不要で自動的にゴミ箱へ移動
- **添付あり**: 削除せず件名・送信元・受信日を一覧で報告し、確認を待つ
- 実行後は「〇件を自動でゴミ箱に移動しました／添付あり〇件は確認待ちです」と一行報告

## アーティファクト出力

結果は以下の構成でHTMLアーティファクトとして公開:
- タイトル: 「デイリーダッシュボード — YYYY年M月D日（曜日）」
- セクション1〜6をカード形式で配置
- ライト/ダークテーマ両対応
- モバイルレスポンシブ
- favicon: 📊

## 注意事項
- MCP接続が切断されている場合は、そのセクションを「未取得」として表示し、エラー内容を明記
- APIトークンやURLは画面に出さない
- メール削除は添付なしのメルマガ系のみ自動実行。添付ありや判断に迷うものは報告のみ
