## 1. 概要
リザストのメルマガ「アロマリア美健康の秘訣」の原稿を、AIが岩本純子先生の文体で自動生成するブラウザツール。
GitHub Pages上で動作する単一HTMLファイル。APIキーは利用者のブラウザにのみ保存され、AI提供元（OpenAI/Anthropic）にのみ送信。

公開URL: https://aromaria.github.io/-/newsletter.html （mainマージ後に利用可能）

## 2. できること
テーマ選択（6種プリセット＋自由入力）、ターゲット読者の設定（8種タグ＋自由入力）、
CTA（行動喚起）の選択（メタトロン予約/スクール/体験セッション/オリエンテーション/全部）、
薬機法自動チェック＆修正、件名5候補の自動生成、A/B/C 3バリエーション比較、
季節自動検出、リザスト最適フォーマット出力、ワンクリックコピー、ファイル保存。

## 3. テーマプリセット
1. メタトロン解析 — 量子力学測定器メタトロンで見えない不調の原因を細胞レベルで可視化
2. 自己治癒力の目覚め — 細胞が本来持っている自己治癒力をセルフケアで呼び覚ます
3. 自然療法を学ぶ — AEAJ総合資格認定校で一生ものの知識を手にする
4. 美と健康の波動 — 波動・エネルギーの観点から心身魂のバランスを見直す
5. 心身魂の三位一体 — 心・身・魂はすべて繋がっている理由と今日からできること
6. アロマで感情解放 — 香りが脳と感情に直接作用するメカニズム

## 4. ターゲット読者ペルソナ
- 原因不明の不調が続き病院では「異常なし」と言われる方
- これ以上お薬を増やしたくない方
- 更年期の心身の揺らぎに悩む40-60代女性
- 内側から輝く美しさと健康を両方叶えたい方
- アロマや自然療法の資格取得に興味がある方
- ストレスで心身が限界、眠れない方
- 家族の健康を自然な方法で守りたい方
- 波動やエネルギー、スピリチュアルなケアに関心がある方

## 5. 薬機法コンプライアンス
自動チェックで検出する禁止表現:
「完治」「治る」「治った」「治癒する」「治療する」「癌/がん/ガンが消」「効果がある」「効きます」
「必ず治」「絶対に治」「100%」「断薬できる」「薬をやめ」「薬が不要」「奇跡的に治」「病気が治」

推奨の置き換え表現:
- 完治/治る → ケア/サポート/整える
- 癌が消えた → QOLが向上/前向きな変化
- 効果がある → 多くの方が変化を実感
- 断薬できる → お薬との付き合い方を見直すきっかけ
- 体験談の後に「個人の感想であり、効果を保証するものではありません」を添える

## 6. 岩本純子先生の文体ルール
- 1文ごとに改行、意味の区切りで空行
- 1行は全角35文字以内（スマホリザスト最適）
- 「☆」「♪」「♡」「✨」「💓」を温かみのアクセントに（1段落2つまで）
- お茶目な表現: 「ぴょん〜♪」「キラキラ✨」「ひとっ飛び♪」
- 語りかけ口調: 「〜なんですよね」「〜なんです♡」
- 押し売りなし。寄り添い→共感→気づき→自然な導線

## 7. メルマガ構成テンプレート
① 冒頭の挨拶（季節感＋読者への語りかけ）: 3〜5行
② テーマ導入（読者の悩みへの共感から入る）: 5〜8行
③ 本題（具体的な知識・岩本純子先生の体験・気づき）: 本文の中核
④ まとめ（読者への温かいメッセージ）: 3〜5行
⑤ CTA（行動喚起）: メタトロン予約/スクール/セッション等への柔らかい誘導
⑥ 署名＋免責表示

## 8. 心理テクニック（プロンプトに組み込み済み）
- 共感ファースト: 読者の悩みを「わかります」と受け止めてから本題へ
- ストーリー: 岩本純子先生自身の体験を物語として語る
- 好奇心ギャップ: 「実は…」「ここが面白いところで」で読み進めたくなる仕掛け
- 社会的証明: 「3,000名以上の方と向き合ってきた中で」を自然に
- 権威性: IFA認定、AEAJ認定校を押し付けず自然に紹介
- 希少性: 「少人数制」「お一人おひとりに合わせた」

## 9. 使い方
1. newsletter.html をブラウザで開く
2. OpenAI または Anthropic のAPIキーを入れて保存
3. テーマをプリセットから選ぶか自由入力
4. ターゲット読者をタグで選択
5. CTA（誘導先）・季節・バリエーション数・文量を設定
6. 「メルマガを生成する」ボタンを押す
7. 件名候補5つ＋本文が生成される
8. 薬機法チェック結果を確認
9. 「コピー」ボタンでリザストに貼り付け

## 10. 技術構成
- 単一HTMLファイル（JavaScript組み込み）
- APIキーはlocalStorageに保存（端末のブラウザのみ）
- OpenAI Chat Completions API / Anthropic Messages API に直接通信
- 外部CDN・フレームワーク不使用（GitHub Pages CSP対応）
- Python CLI版も別途あり: tools/newsletter_agent.py

## 12. リザストAPI読者登録（serialcdセッション方式）

外部サイト・ランディングページからリザストのメルマガ読者を直接登録できるAPI。
Bearer APIキー（rs_live_...）とは別の認証方式で、フロントエンド埋め込み向けに設計されている。

### 仕組み（2ステップ）
1. **セッションID取得**: `GET /api/create_api_session/{serialcd}` → session_id を取得
2. **読者登録実行**: `GET /api/new_subscribe_api/{serialcd}?session_id={session_id}&mid={mail_magazine_id}&email_address={email}`

### パラメータ
| 名前 | 必須 | 説明 |
|---|---|---|
| serialcd | ○ | メルマガ管理画面のAPIアイコンから取得する固有コード |
| session_id | ○ | Step 1で取得（`api_session_` で始まる） |
| mid | ○ | メルマガのmail_magazine_id |
| email_address | ○ | 登録するメールアドレス |
| lname | - | 姓（任意） |
| fname | - | 名（任意） |

### 特徴
- メソッドはGET（POSTではない）
- 成功 = レスポンスコード 200 OK
- serialcdはフロントエンド埋め込み前提（APIキーとは別物）
- セッションIDは都度取得が安全（有効期限あり）
- 「読者登録」専用。記事の作成・保存には使えない

### 活用シーン
- 自社サイト（about.html 等）にメルマガ登録フォームを設置
- ランディングページから直接リザストに読者登録
- リザストの登録フォームページに飛ばさずサイト内で完結

## 13. バッチ処理ワークフロー（Claude Code連携）

リザストAPIへの通信はCloud環境からブロックされるため、Mac側でAPIを叩きGit経由で受け渡す。

### フロー
1. Mac: `./scripts/batch-fetch.sh` → 記事取得 → `out/articles/` → git push
2. Claude Code: git pull → 記事をリライト → `out/rewritten/` → git push
3. Mac: git pull → `./scripts/batch-save.sh` → リザストにprivateで保存

### 新規記事の注意
- `id: 0` のファイル（origin story等）は batch-save（既存記事更新用）では保存不可
- 新規記事は `/api/create_mail_magazine_article` で `mail_magazine_id` を指定して作成する必要がある

## 14. リザスト運用ナレッジ（公式FAQ要約）

リザスト公式ブログ（reservestock.hatenablog.jp）のFAQから抽出した運用知識。

### アカウント管理
- ログインID・パスワード・メールアドレスの変更: 「全体設定」→「パスワードとアカウント」
- 有償版解約: 解約申請フォームからクラウドリンクに連絡（代理店契約は代理店へ）
- @reservestock.jp ドメインのメールアドレス設定可能（送信元として使用→到達率向上）

### HTMLメール vs 文字メール
- HTMLメール: 文字装飾・写真挿入・開封確認が可能だが、携帯キャリアには非対応（2017年12月〜）
- 文字メール: 装飾不可だが、すべての端末で表示可能
- **重要**: HTMLメール作成時は「文字メールタブ」にも必ず記入（携帯ユーザー対策）

### テスト配信・予約配信
- テスト配信: 送信元メールアドレス宛に送信される（本番前に必ず確認）
- 予約配信: 配信予定日時を選択 →「すぐに保存/配信の予約」で完了

### ステップメール
- 配信済みメルマガ記事をステップメールに追加可能
- 手順: メルマガ記事一覧 → 記事タイトルクリック → 編集画面 →「この記事をステップメールに追加」
- 注意: 季節のあいさつやイベント募集リンクなど時限的な内容は削除・修正すること

### 記事の状態（public_status）
| 状態 | 説明 |
|---|---|
| private | 非公開（下書き） |
| public | 公開（配信可能） |
| backnumber | バックナンバーとして公開 |

### 読者登録のフロー
1. 登録フォームから読者が自分で登録
2. 登録完了メールのリンクをクリック（ダブルオプトイン）
3. 管理者が手動で登録も可能
4. serialcd API で外部サイトから直接登録も可能

### 岩本さんの運用への活用
1. リライト済みの良質な記事 → ステップメールに追加 → 新規読者に自動配信
2. 過去の良記事 → バックナンバー公開 → SEO効果＆新規読者獲得
3. HTMLメルマガには必ず文字メールを併用
4. about.html / client-voices.html にメルマガ登録フォームを設置（serialcd API活用）

## 15. 岩本純子の文体解析（メルマガ66件から機械的に抽出）

### 文章の構造
- 書き出し: `((customer_name))` → 名乗り（英国IFA認定国際アロマセラピスト） → 季節の話題 → 本題
- 展開: 問いかけで引き込む → 本題 → 体験談 → まとめ → CTA → 締め（感謝）
- 答えを押しつけず「気づき」を促す構成

### 絵文字・文末リズム
- ♪（904回）、♡（552回）、☆（525回）が三大記号
- 文末の約3割は句点「。」ではなく♪♡☆で閉じる → 硬くならない温かいリズム
- ✨（75回）は特別感の演出に

### 読者への呼びかけ
- `((customer_name))`（180回）で名前呼び → 1対1のトーン
- 「あなた」（110回）で語りかけ
- 「〜してみませんか？」（提案型）、「〜ではないでしょうか？」（気づき型）、「〜ですよね」（共感型）

### 感情・温かさ
- 「ありがとう」401回、「幸せ」207回、「感謝」171回 — 感謝と幸せが軸
- 「応援」39回、「嬉しい」30回、「愛」24回、「心を込め」14回、「寄り添」10回

### 独自用語
- 「美健康」（64回）: 美しさと健康の両立。岩本さんの造語
- 「メタトロン」（511回）: 周波数測定機器。主力サービス
- 「身体の声/サイン/メッセージ」: MSPの核心表現
- 「心身魂のトータルケア」: 名乗りの定型
- 「地球ランド」: 地球を遊び場に見立てた表現

### 敬語レベル
- 「です・ます」ベースに♪♡を添えて柔らかくする
- 「いただく」207回、「いたします」78回 — 丁寧だが堅苦しくない
- 「だって」「そんな」など口語的な接続で話しかけるトーン

### 文の長さ
- 平均81.2文字（やや長め）。1行を短く改行してメールの読みやすさを確保

### リライト時の鉄則
1. ♪♡☆のリズムを保つ（文末の3割）
2. 「あなた」で1対1に語りかける
3. 答えを押しつけず「〜してみませんか？」で気づきを促す
4. 「体」→「身体」に統一（熟語はそのまま）
5. ありがとう・感謝・幸せは削らない
6. 「だって」「そんな」「実は」で口語的な柔らかさ
7. テンプレート変数を保持: `((customer_name))`, `((friendly_name))`, `((serial_code))`, `((mail_footer))`
8. 「美健康」「地球ランド」「心身魂のトータルケア」はそのまま使う
9. 臨床例・体験談は削除しない。必要なら※注釈を添えるのみ
