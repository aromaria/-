## 1. 概要
リザストのメルマガ「アロマリア美健康の秘訣」の原稿を、AIが岩本純子先生の文体で自動生成するブラウザツール。
GitHub Pages上で動作する単一HTMLファイル。APIキーは利用者のブラウザにのみ保存され、AI提供元（OpenAI/Anthropic）にのみ送信。

公開URL: https://aromaria.github.io/-/newsletter.html （mainマージ後に利用可能）

## 2. できること
テーマ選択（6種プリセット＋自由入力）、ターゲット読者の設定（8種タグ＋自由入力）、
CTA（行動喚起）の選択（メタトロン予約/スクール/体験セッション/オリエンテーション/全部）、
薬機法自動チェック＆修正、件名5候補の自動生成、A/B/C 3バリエーション比較、
季節自動検出、リザスト最適フォーマット出力、ワンクリックコピー、ファイル保存。

## 3. テーマプリセット
1. メタトロン解析 — 量子力学測定器メタトロンで見えない不調の原因を細胞レベルで可視化
2. 自己治癒力の目覚め — 細胞が本来持っている自己治癒力をセルフケアで呼び覚ます
3. 自然療法を学ぶ — AEAJ総合資格認定校で一生ものの知識を手にする
4. 美と健康の波動 — 波動・エネルギーの観点から心身魂のバランスを見直す
5. 心身魂の三位一体 — 心・身・魂はすべて繋がっている理由と今日からできること
6. アロマで感情解放 — 香りが脳と感情に直接作用するメカニズム

## 4. ターゲット読者ペルソナ
- 原因不明の不調が続き病院では「異常なし」と言われる方
- これ以上お薬を増やしたくない方
- 更年期の心身の揺らぎに悩む40-60代女性
- 内側から輝く美しさと健康を両方叶えたい方
- アロマや自然療法の資格取得に興味がある方
- ストレスで心身が限界、眠れない方
- 家族の健康を自然な方法で守りたい方
- 波動やエネルギー、スピリチュアルなケアに関心がある方

## 5. 薬機法コンプライアンス
自動チェックで検出する禁止表現:
「完治」「治る」「治った」「治癒する」「治療する」「癌/がん/ガンが消」「効果がある」「効きます」
「必ず治」「絶対に治」「100%」「断薬できる」「薬をやめ」「薬が不要」「奇跡的に治」「病気が治」

推奨の置き換え表現:
- 完治/治る → ケア/サポート/整える
- 癌が消えた → QOLが向上/前向きな変化
- 効果がある → 多くの方が変化を実感
- 断薬できる → お薬との付き合い方を見直すきっかけ
- 体験談の後に「個人の感想であり、効果を保証するものではありません」を添える

## 6. 岩本純子先生の文体ルール
- 1文ごとに改行、意味の区切りで空行
- 1行は全角35文字以内（スマホリザスト最適）
- 「☆」「♪」「♡」「✨」「💓」を温かみのアクセントに（1段落2つまで）
- お茶目な表現: 「ぴょん〜♪」「キラキラ✨」「ひとっ飛び♪」
- 語りかけ口調: 「〜なんですよね」「〜なんです♡」
- 押し売りなし。寄り添い→共感→気づき→自然な導線

## 7. メルマガ構成テンプレート
① 冒頭の挨拶（季節感＋読者への語りかけ）: 3〜5行
② テーマ導入（読者の悩みへの共感から入る）: 5〜8行
③ 本題（具体的な知識・岩本純子先生の体験・気づき）: 本文の中核
④ まとめ（読者への温かいメッセージ）: 3〜5行
⑤ CTA（行動喚起）: メタトロン予約/スクール/セッション等への柔らかい誘導
⑥ 署名＋免責表示

## 8. 心理テクニック（プロンプトに組み込み済み）
- 共感ファースト: 読者の悩みを「わかります」と受け止めてから本題へ
- ストーリー: 岩本純子先生自身の体験を物語として語る
- 好奇心ギャップ: 「実は…」「ここが面白いところで」で読み進めたくなる仕掛け
- 社会的証明: 「3,000名以上の方と向き合ってきた中で」を自然に
- 権威性: IFA認定、AEAJ認定校を押し付けず自然に紹介
- 希少性: 「少人数制」「お一人おひとりに合わせた」

## 9. 使い方
1. newsletter.html をブラウザで開く
2. OpenAI または Anthropic のAPIキーを入れて保存
3. テーマをプリセットから選ぶか自由入力
4. ターゲット読者をタグで選択
5. CTA（誘導先）・季節・バリエーション数・文量を設定
6. 「メルマガを生成する」ボタンを押す
7. 件名候補5つ＋本文が生成される
8. 薬機法チェック結果を確認
9. 「コピー」ボタンでリザストに貼り付け

## 10. 技術構成
- 単一HTMLファイル（JavaScript組み込み）
- APIキーはlocalStorageに保存（端末のブラウザのみ）
- OpenAI Chat Completions API / Anthropic Messages API に直接通信
- 外部CDN・フレームワーク不使用（GitHub Pages CSP対応）
- Python CLI版も別途あり: tools/newsletter_agent.py
