
# Premiere Pro 自動編集ルール（premiere MCP を使うときは必ず守る）

## 大原則：元の動画・元のシーケンスは使わない。コピーだけを編集する
- 元の素材ファイル（例: `IMG_9671.MOV`）と、元のシーケンス（例: `IMG_9671`）は**読み取り専用**として扱う。編集・移動・名前変更・削除をしない。
- 編集してよいのは、**素材のコピー**（`〇〇 のコピー.MOV`）から作った **`〇〇 のコピー` という名前のシーケンス**だけ。

## 編集を頼まれたら、次の流れを自動で進める（ユーザーに手作業をさせない）
1. **確認（読み取り）**: `ping` で接続を確認し、プロジェクト名・アクティブシーケンス・素材ファイルのパスを調べる。
2. **素材のコピー**: 元素材と同じフォルダに `〇〇 のコピー.拡張子` を作る。
   - Bash で `cp -n "元のパス" "コピーのパス"` を使う（`-n` で既存ファイルを上書きしない）。
   - コピーが既にあればそれを使う。元ファイルには `cp` の読み取り以外で触れない（`mv`・`rm`・上書き禁止）。
3. **読み込み**: `import_media` でコピーをプロジェクトに読み込む（既に読み込み済みなら再利用）。
4. **シーケンス作成**: `create_sequence_from_clips` でコピーから `〇〇 のコピー` シーケンスを作り、それを開く（既にあれば再利用）。
5. **対象の確認**: アクティブシーケンス名が「のコピー」で終わり、クリップがすべてコピー素材を参照していることを確かめる。満たさなければ編集せず止まって報告する。
6. **編集**: どのツールで・どこを・どう変えるかを日本語で短く示し、そのまま実行する。
   ユーザーが「確認してから」「計画だけ」と言った場合だけ、「実行して」と言われるまで待つ。
7. **報告**: 変更内容を日本語で報告し、⌘S での保存を促す。やり直しは ⌘Z で戻せることを伝える。

## 守ること
- 依頼された編集以外を勝手に追加しない。判断に迷う変更は止まって確認する。
- 使ってよい権限は `inspect` と `edit` だけ。`export`・`filesystem`・`unsafe-script` が必要になったら、**勝手に追加せず**理由を説明してユーザーの承認を待つ。
- Bash で行ってよいのは手順2のコピーだけ。`~/.claude/` の設定や MCP の登録内容は変更しない。
