
# Premiere Pro 自動編集ルール（premiere MCP を使うときは必ず守る）

## 大原則：元の動画・元のシーケンスは使わない。コピーだけを編集する
- 元の素材ファイル（例: `IMG_9671.MOV`）と、元のシーケンス（例: `IMG_9671`）は**読み取り専用**として扱う。編集・移動・名前変更・削除をしない。
- 編集してよいのは、**素材のコピー**（`〇〇 のコピー.MOV`）から作った **`〇〇 のコピー` という名前のシーケンス**だけ。

## 編集を始める前に必ず確認する（読み取りのみ）
1. `ping` で接続を確認し、開いているプロジェクト名とアクティブシーケンス名を報告する。
2. アクティブシーケンス名が「のコピー」で終わっているか確認する。
3. そのシーケンス内のクリップが、すべて「のコピー」の素材ファイルを参照しているか確認する。
4. 1〜3 のどれかが満たされない場合は、**編集せずに止まり**、下の「コピーの作り方」をユーザーに案内する。
   素材ファイルのコピーは Claude が作らない（filesystem 権限は無効）。ユーザーが Finder で作る。

## コピーの作り方（ユーザーに案内する手順）
1. Premiere のプロジェクトパネルで元素材を右クリック →「Finderで表示」→ Finder で ⌘D（`〇〇 のコピー.MOV` ができる）
2. Premiere で ファイル > 読み込み（⌘I）→ コピーを読み込む
3. コピーを右クリック →「クリップに合わせた新規シーケンス」→ シーケンス名が `〇〇 のコピー` になっていることを確認 → ⌘S

## 編集の進め方
1. まず読み取りだけで内容を調べ、**どのツールで・どこを・どう変えるか**の計画を日本語で示す。
2. ユーザーが「実行して」と言うまで編集ツールを呼ばない。
3. 実行後は、変更した内容を日本語で報告し、ユーザーに ⌘S での保存を促す。やり直しは ⌘Z で戻せることも伝える。
4. 計画にない編集を途中で追加しない。必要になったら止まって確認を取る。

## 権限について
- 使ってよい権限は `inspect` と `edit` だけ。`export`・`filesystem`・`unsafe-script` が必要になったら、**勝手に追加せず**理由を説明してユーザーの承認を待つ。
- `~/.claude/` の設定や MCP の登録内容は変更しない。
