# Genius Insight / 量子バイオフィードバック調査資料

## 概要
Genius Insightは、ネルソン氏（William C. Nelson）が開発した「量子バイオフィードバック」デバイスの系譜を引くスマホアプリ。このメモでは、元となるデバイスの歴史・問題点・そしてスマホアプリ化された現在の状況をまとめる。

---

## ネルソン氏（William C. Nelson）の経歴

| 年 | 出来事 |
|---|---|
| 1951 | 誕生 |
| 1984 | コロラド州に移住、自作の医療デバイス **EPFX**（Electro Physiological Feedback Xrroid）の販売開始 |
| 1989 | FDA（米国食品医薬品局）にバイオフィードバック機器メーカーとして会社「Eclosion」を登録。法的にはストレス軽減ツールとしてのみ販売可能 |
| 1992 | FDAが虚偽の医療効能表示を指摘、ソフトウェアの139台分のリコール命令。ネルソン氏は従わず販売を継続 |
| 1996 | **詐欺罪9件で起訴**。米国から逃亡し**ハンガリー・ブダペスト**に移住 |
| 1996 | ブダペストで新デバイス **QXCI**（Quantum Xrroid Consciousness Interface）を開発 |
| 2002 | **SCIO**（Scientific Consciousness Interface Operation）のプロトタイプ完成。ラテン語で「知る」の意 |
| 現在 | ブダペストから世界中に販売を継続。QX Ltd.として運営。別名 Desire Dubounet としても活動 |

---

## デバイスの系譜

```
EPFX (1984) → QXCI (1996) → SCIO (2002) → EDUCTOR → スマホアプリ化
                                                        ↓
                                              Genius Insight (2012〜)
```

### 各デバイスの名称
| 名称 | 正式名 | 時期 |
|---|---|---|
| EPFX | Electro Physiological Feedback Xrroid | 1984〜 |
| QXCI | Quantum Xrroid Consciousness Interface | 1996〜 |
| SCIO | Scientific Consciousness Interface Operation | 2002〜 |
| EDUCTOR | (SCIOの後継) | 2000年代後半〜 |

### 「Xrroid」の意味
造語。「電気生理学的手段を用い、短時間で数千項目を高速テストし、コンピュータが計算してデータ化する」という意味を持たせたもの。

---

## デバイスの仕組み（主張）

1. 患者の身体に電極を接続（または声を録音）
2. 微弱な電気信号（または音声周波数）を分析
3. 「量子力学的原理」により、数千種類の物質（感情・チャクラ・経絡・栄養素等）の周波数と比較
4. 不均衡を検出し、修正周波数を送り返して「バランスを整える」

### 科学的評価
- 科学コミュニティは「バイオエネルギー的な力」の存在を認めていない
- 「量子力学」という用語は、実際の量子物理学とは無関係に使われている
- 査読済み論文や臨床試験による有効性の証明はない
- Quackwatch（医療詐欺監視サイト）が詳細な批判記事を掲載

---

## 法的問題・FDA規制

### FDAの立場
- バイオフィードバック機器は **クラスII医療機器** に分類
- 法的に許可される用途は **ストレス軽減のみ**
- 疾患の診断・治療に使用することは **違法**

### ネルソン氏の違反
1. FDAに「ストレス軽減ツール」として登録しながら、実際には疾患の診断・治療を謳って販売
2. 1992年のリコール命令を無視
3. 1996年に詐欺罪9件で起訴されるも、米国から逃亡
4. ハンガリーから国際販売を継続（米国法の執行が困難）
5. FDAは後に輸入禁止措置を実施

### 販売者の法律回避手法
- 「バイオフィードバック機器」として登録し、表向きはストレス軽減用
- 実際の販売・マーケティングでは健康改善・疾患治療を示唆
- 免責事項に「医療アドバイスではない」「健康教育ツール」と記載して法的リスクを回避

---

## 被害の実態

- 推定 **10,000台以上** のEPFX/SCIOが米国内のクリニック・家庭に存在
- 北西部（シアトル周辺）が最多の販売地域
- 重篤な疾患（がん等）の患者が、このデバイスを信じて **正規の医療を受けずに死亡** した事例が報告されている
- 「絶望的な病気を抱える人々を食い物にしている」（Seattle Times記事の表現）

## スマホアプリへの進化：Genius Insight

### 経緯
- 開発者はSCIO/EDUCTORを1999年から使用していた人物
- 従来のデバイスは高額（数千ドル〜）・操作が複雑
- 2012年、同じ「量子バイオフィードバック」技術をスマホアプリ化して発売

### Genius Insightの仕組み
1. ユーザーが10〜15秒間、声を録音
2. FFT（高速フーリエ変換）で音声を周波数分析
3. データベース内の物質（感情・チャクラ・経絡等）の周波数と比較
4. 不均衡を検出し、「治療用音響周波数」のプレイリストを生成
5. 「遠隔バイオフィードバック」として、対面なしでクライアントにセッション提供可能

### 価格体系
| パッケージ | 価格 | 内容 |
|---|---|---|
| 月額サブスク | $119/月 | 基本利用 |
| Core（個人用） | $597〜697 | 自分専用 |
| Practitioner | $1,397 | 遠隔セッション提供可 |
| Professional | $2,497 | 上位機能 |
| Mastery（買い切り） | $3,497 | 全機能・生涯アクセス |

### 販売手法（ドリップメール）
- 無料トライアル（3日間）でアプリを体験させる
- 毎日メールで段階的に情報提供（バイオフィードバック→遠隔セッション→パッケージ紹介）
- 個別相談（サンドラとの予約）への誘導
- 典型的なファネル型販促（トライアル→教育→相談→高額契約）

## 問題点のまとめ

### 科学的問題
- 「量子力学」の用語を実際の物理学とは無関係に使用（量子力学ウォッシング）
- 声の周波数から身体の不均衡を検出できるという主張に科学的根拠なし
- 独立した臨床試験・査読論文が存在しない

### 法的・倫理的問題
- 創始者が詐欺罪で起訴された逃亡中の人物
- FDAが輸入を禁止したデバイスの技術を基盤としている
- 「健康教育ツール」という免責で医療機器規制を回避
- 重篤な患者が正規医療の代わりに使用するリスク

### ビジネスモデルの問題
- 高額な価格設定（アプリとしては異常に高い）
- 自社サイトのレビューのみで、独立した第三者評価がない
- トライアルからの強い販売圧力
- 類似デバイス（Healy等）でも同様の詐欺的手法が問題視されている
