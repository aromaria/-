# Genius Insight / 量子バイオフィードバック調査資料

## 概要
Genius Insightは、ネルソン氏（William C. Nelson）が開発した「量子バイオフィードバック」デバイスの系譜を引くスマホアプリ。このメモでは、元となるデバイスの歴史・問題点・そしてスマホアプリ化された現在の状況をまとめる。

---

## ネルソン氏（William C. Nelson）の経歴

| 年 | 出来事 |
|---|---|
| 1951 | 誕生 |
| 1984 | コロラド州に移住、自作の医療デバイス **EPFX**（Electro Physiological Feedback Xrroid）の販売開始 |
| 1989 | FDA（米国食品医薬品局）にバイオフィードバック機器メーカーとして会社「Eclosion」を登録。法的にはストレス軽減ツールとしてのみ販売可能 |
| 1992 | FDAが虚偽の医療効能表示を指摘、ソフトウェアの139台分のリコール命令。ネルソン氏は従わず販売を継続 |
| 1996 | **詐欺罪9件で起訴**。米国から逃亡し**ハンガリー・ブダペスト**に移住 |
| 1996 | ブダペストで新デバイス **QXCI**（Quantum Xrroid Consciousness Interface）を開発 |
| 2002 | **SCIO**（Scientific Consciousness Interface Operation）のプロトタイプ完成。ラテン語で「知る」の意 |
| 現在 | ブダペストから世界中に販売を継続。QX Ltd.として運営。別名 Desire Dubounet としても活動 |

## デバイスの系譜

```
EPFX (1984) → QXCI (1996) → SCIO (2002) → EDUCTOR → スマホアプリ化
                                                        ↓
                                              Genius Insight (2012〜)
```

### 各デバイスの名称
| 名称 | 正式名 | 時期 |
|---|---|---|
| EPFX | Electro Physiological Feedback Xrroid | 1984〜 |
| QXCI | Quantum Xrroid Consciousness Interface | 1996〜 |
| SCIO | Scientific Consciousness Interface Operation | 2002〜 |
| EDUCTOR | (SCIOの後継) | 2000年代後半〜 |

### 「Xrroid」の意味
造語。「電気生理学的手段を用い、短時間で数千項目を高速テストし、コンピュータが計算してデータ化する」という意味を持たせたもの。

---

## デバイスの仕組み（主張）

1. 患者の身体に電極を接続（または声を録音）
2. 微弱な電気信号（または音声周波数）を分析
3. 「量子力学的原理」により、数千種類の物質（感情・チャクラ・経絡・栄養素等）の周波数と比較
4. 不均衡を検出し、修正周波数を送り返して「バランスを整える」

### 科学的評価
- 科学コミュニティは「バイオエネルギー的な力」の存在を認めていない
- 「量子力学」という用語は、実際の量子物理学とは無関係に使われている
- 査読済み論文や臨床試験による有効性の証明はない
- Quackwatch（医療詐欺監視サイト）が詳細な批判記事を掲載

---

## 法的問題・FDA規制

### FDAの立場
- バイオフィードバック機器は **クラスII医療機器** に分類
- 法的に許可される用途は **ストレス軽減のみ**
- 疾患の診断・治療に使用することは **違法**

### ネルソン氏の違反
1. FDAに「ストレス軽減ツール」として登録しながら、実際には疾患の診断・治療を謳って販売
2. 1992年のリコール命令を無視
3. 1996年に詐欺罪9件で起訴されるも、米国から逃亡
4. ハンガリーから国際販売を継続（米国法の執行が困難）
5. FDAは後に輸入禁止措置を実施

### 販売者の法律回避手法
- 「バイオフィードバック機器」として登録し、表向きはストレス軽減用
- 実際の販売・マーケティングでは健康改善・疾患治療を示唆
- 免責事項に「医療アドバイスではない」「健康教育ツール」と記載して法的リスクを回避

---

## 被害の実態

- 推定 **10,000台以上** のEPFX/SCIOが米国内のクリニック・家庭に存在
- 北西部（シアトル周辺）が最多の販売地域
- 重篤な疾患（がん等）の患者が、このデバイスを信じて **正規の医療を受けずに死亡** した事例が報告されている
- 「絶望的な病気を抱える人々を食い物にしている」（Seattle Times記事の表現）

## スマホアプリへの進化：Genius Insight

### 開発者：Ryan Williams
- 南アフリカ・イギリスでホリスティックヘルス業界に約20年従事
- 1999年からSCIO/EDUCTOR等の量子バイオフィードバック機器を使用
- 元妻と共に高額バイオフィードバック機器の国際販売会社を15年以上運営
- 従来のデバイスは高額・操作が複雑だったため、2012年にスマホアプリ化を決意
- 「瞑想中にインスピレーションを受けた」と語っている
- 現在までに30以上のカスタマイズ済みアプリソリューションを制作、旗艦アプリがGenius Insight

### 会社情報
- 社名: **Insight Health Apps**（略称 IHA）
- サイト: insighthealthapps.com / geniusbiofeedback.com / geniusinsight.app（複数ドメイン運用）
- アフィリエイト報酬: 初回販売の**20%**（MLMではないと明記。ダウンラインや継続報酬なし）
- アフィリエイト例: Master Frequency Eliteパッケージ販売で$1,099の報酬

### Genius Insightの仕組み（詳細）

#### 音声分析プロセス
1. ユーザーが**15秒間**、声を録音
2. **FFT（高速フーリエ変換）** で音声の波形パターンを分解・簡略化
3. 声のトーンの周波数を、テスト対象アイテムの周波数と比較
4. 差異を数値に変換し、主要・副次的な「反応物質」を特定

#### 比較対象データベース（自称）
声の周波数と比較される項目:
- 感情的シグネチャー
- チャクラ
- 経絡（メリディアン）
- ソルフェジオ音調
- ハーブ
- ホメオパシー
- ウイルス活動
- オーラフィールドの乱れ
- 鍼灸の不均衡

#### 出力
- 個別にカスタマイズされた「修正音響周波数」のプレイリストを自動生成
- スマホ・ヘッドホン・またはQuanta Capsule経由で再生

### Quanta Capsule（ハードウェア）
- Genius Insightアプリと連携する物理デバイス
- プラクティショナーが遠隔セッションの結果を書き出し、クライアントが自宅で再生
- セッション回数制限なし（無制限リスニング）
- バルク割引あり（10個パック、20個パック、50個パック）
- プラクティショナーがクライアントに配布し、遠隔ビジネスを構築する仕組み

### 遠隔バイオフィードバックの流れ
1. クライアントが声を録音（ボイスメール・ボイスメモ等）
2. プラクティショナーがGenius Insightアプリに音声をアップロード（暗号化サーバー経由）
3. アプリが分析→バランシング周波数を生成
4. 周波数をQuanta Capsuleにエクスポート
5. クライアントが自宅でCapsuleから周波数を聴く

## 問題点のまとめ

### 科学的問題
- 「量子力学」の用語を実際の物理学とは無関係に使用（量子力学ウォッシング）
- 声の周波数から身体の不均衡を検出できるという主張に科学的根拠なし
- 独立した臨床試験・査読論文が存在しない
- 唯一の「研究」は被験者6名の非査読PDF（科学的に無価値）
- FFT自体は確立された数学的手法だが、声→チャクラ・経絡の対応付けに根拠なし

### 法的・倫理的問題
- 技術の源流であるEPFX/SCIOの創始者が詐欺罪で起訴された逃亡中の人物
- FDAが輸入を禁止したデバイスの技術思想を基盤としている
- 「健康教育ツール」という免責で医療機器規制を回避
- 重篤な患者が正規医療の代わりに使用するリスク
- 独自の「認定資格」を発行しているが、公的機関（BCIA等）とは無関係

### ビジネスモデルの問題
- 高額な価格設定（アプリとしては異常。最高で総額$7,494）
- 自社サイトのレビューのみで、独立した第三者評価がない
- トライアルからの強い販売圧力（3日間で段階的にエスカレーション）
- アフィリエイト20%報酬で紹介者にも高い金銭的インセンティブ
- Quanta Capsuleのバルク販売でプラクティショナーに在庫を持たせる構造
- 複数ドメイン運用（insighthealthapps.com / geniusbiofeedback.com / geniusinsight.app / ilovemygenius.com / biofeedbackvoicescan.com）で信頼性を演出
- 類似デバイス（Healy等）でも同様の詐欺的手法が問題視されている
