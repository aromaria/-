# 久保田様ご予約確認

## 📅 トリートメント10回コース回数券カレンダー生成

### 概要
久保田寛様のトリートメント10回コースの来店予定を、Macのカレンダーアプリに自動登録するツール。

### 公開URL
🔗 https://aromaria.github.io/-/treatment_ticket_calendar.html

### 何ができるか
- 10回の来店予定日を入力
- iCal形式（.ics）でカレンダーファイルを自動生成
- Macカレンダーアプリにインポート可能
- 各回のイベント情報に料金情報を記載

### 料金情報
| 項目 | 金額 |
|------|------|
| 正規価格（1回） | 20,800円（税込22,880円） |
| 割引後価格（1回） | 17,800円（税込19,580円） |
| 割引額（1回） | 3,300円off |
| 10回の合計 | 195,800円（税込） |
| **10回で節約** | **33,000円お得** |

### 使い方（ステップバイステップ）

#### ステップ1：ページを開く
```
https://aromaria.github.io/-/treatment_ticket_calendar.html
```

#### ステップ2：顧客名を入力
- 「久保田寛」と入力

#### ステップ3：10回の来店予定日を入力
- 1回目～10回目の日付を入力
- 予約が決まっていない回は空欄でOK
- 例：2024年9月15日のような形式で入力

#### ステップ4：プレビューを確認
- 「カレンダーを生成」をクリック
- 各回の予定が表示される

#### ステップ5：ダウンロード
- 「カレンダーをダウンロード（.ics）」をクリック
- `久保田寛_treatment_ticket.ics` がダウンロードされる

#### ステップ6：Macカレンダーにインポート
- ダウンロードしたファイルをダブルクリック
- または、Macのカレンダーアプリにドラッグ&ドロップ
- カレンダーに10回の予約が表示される

### iCal形式で記載される情報
各イベントに以下の情報が含まれます：

```
[顧客名] - トリートメント[回数]回目／全10回

説明：
- トリートメント10回コース（1回 17,800円・税込19,580円）
- 正規価格 20,800円（税込22,880円）→ 17,800円（税込19,580円）に割引
- 10回目のイベント：「最終回）10回の合計金額：195,800円（税込）」と記載
```

### ブラウザ側での便利機能
- **自動保存**：顧客名と日付がローカルストレージに自動保存
- **再度開いた時**：前回の入力が残っているので、追加・修正が簡単
- **リセット**：「リセット」ボタンで入力フォームに戻る

### 技術仕様
- **形式**：iCalendar（RFC 5545準拠）
- **タイムゾーン**：Asia/Tokyo
- **イベント時間**：10:00～11:00（1時間）
- **ファイル名**：`[顧客名]_treatment_ticket.ics`

### よくある質問

**Q：複数の顧客に対応できますか？**  
A：はい。顧客名を変えて何度でも使用できます。前回の入力はローカルストレージに保存されているので、顧客名を入力し直すと自動で新規作成になります。

**Q：Googleカレンダーにも入力できますか？**  
A：iCal形式なので、GoogleカレンダーにもインポートできますURL経由、またはダウンロードしたファイルをアップロードしてください。

**Q：日付を後から変更できますか？**  
A：iCal形式で出力後は、Macカレンダー上で直接編集するか、もう一度このツールで日付を修正してファイルを再ダウンロードしてインポートしてください。
