# 回数券残数・予約管理システム

## 🎯 目的

**お客様とお店側が同時に確認できる**回数券管理システムを構築

```
お客様：「あと何回分残ってるか？」をいつでも確認
お店側：「どのお客様がいつ来るか？」をリアルタイム確認
```

---

## 📊 実装パターン（3つの選択肢）

### 【パターン1：Google Sheets 共有版】⭐ 最もシンプル

#### 仕組み
```
Google Sheets で管理
  ↓
スタッフと顧客にリンク共有
  ↓
顧客：自分の行だけ見える
スタッフ：全顧客を見える
```

#### 費用
```
あなた：ゼロ円
顧客：ゼロ円
```

#### 準備時間
```
初期設定：30分
毎月運用：来店時に✓をつける（2分/人）
```

#### メリット
```
✓ 無料
✓ 誰でも使える
✓ 即座に実装可能
✓ あなたに負担がない
```

#### デメリット
```
✗ デザインが素朴（業務的）
✗ パスワード管理が必要
✗ 手動で来店記録をつける
```

---

### 【パターン2：Web ページ版】⭐ バランス型

#### 仕組み
```
簡単な Web ページを作成
  ↓
顧客ID でログイン
  ↓
顧客：自分の情報だけ表示
スタッフ：全顧客の情報を表示
  ↓
Firebase（Google）の無料枠で動作
```

#### 費用
```
あなた：ゼロ円（Firebase 無料枠）
顧客：ゼロ円
```

#### 準備時間
```
初期設定：2～3時間（専門知識が必要）
毎月運用：ほぼ自動
```

#### メリット
```
✓ 見た目が良い
✓ 完全自動化
✓ モバイル対応
✓ リアルタイム同期
```

#### デメリット
```
✗ 実装に技術知識が必要
✗ バグがあると対応が必要
✗ セキュリティ設定が複雑
```

---

### 【パターン3：SaaS 連携版】⭐ 高機能・費用発生

#### 仕組み
```
既存の回数券管理 SaaS を使う
例：Reservestock（リザスト）の回数券機能
    LINE Official Account で確認
    
または：
Stripe Billing を使用
```

#### 費用
```
あなた：ゼロ円（ユーザーが契約）
顧客：月額 3,000～5,000円
（顧客が月額課金サービスを契約）
```

#### 準備時間
```
初期設定：1～2時間（外部サービスの設定）
毎月運用：自動
```

#### メリット
```
✓ 完全に自動化
✓ プロフェッショナル
✓ セキュリティが高い
```

#### デメリット
```
✗ 顧客が月額課金を負担
✗ 複雑な設定
✗ あなたも学習が必要
```

## 🌟 推奨：パターン1（Google Sheets 版）

ユーザーの「負担ゼロ」を徹底するなら、これが最適です。

### 実装手順

#### Step 1：テンプレート Google Sheet を作成

```
【シート内容】

顧客名 | 開始日 | 1回目 | 2回目 | 3回目 | ... | 10回目 | 残数 | メモ
-----|--------|-------|--------|--------|-----|--------|------|-------
久保田寛 | 2026/1/1 | ✓ | ✓ |  |  |  |  | 8 | 次回2月15日予定
田中太郎 | 2026/1/15 | ✓ |  |  |  |  |  |  | 9 | 来月開始予定
```

#### Step 2：アクセス権を設定

```
【スタッフ用リンク】
→ シート全体が見える
→ 全顧客の情報を管理

【顧客用リンク】
→ 自分の行だけ見える
（Google Sheet の「フィルタ表示」機能を使用）
```

#### Step 3：来店時に記入

```
顧客が来店
  ↓
スタッフが該当するセルに「✓」をつける
  ↓
顧客は「残数」を確認できる
  ↓
自動的に「残回数」の数式が計算される
```

### テンプレート内容

```
【顧客向け版（見える情報）】

名前：久保田寛
開始日：2026年1月1日

来店予約日：
□ 1回目：2026年1月15日（済み）✓
□ 2回目：2026年2月1日（済み）✓
□ 3回目：2026年3月1日（未来）
□ 4回目：2026年4月1日（未定）
...
□ 10回目：2026年10月1日（未定）

残回数：8回

次回予約：2026年3月1日
メモ：事前にご連絡ください
```

```
【スタッフ向け版（見える情報）】

顧客名 | 開始日 | 1回目 | 2回目 | 3回目 | 4回目 | ... | 10回目 | 残数 | 次回予約 | 連絡先
------|--------|-------|-------|-------|-------|-----|--------|------|---------|-------
久保田寛 | 1/1 | ✓ | ✓ | 3/1予定 | - | ... | - | 8 | 3/1 | 090-XXXX
田中太郎 | 1/15 | ✓ | - | - | - | ... | - | 9 | 2/15 | 090-YYYY
鈴木花子 | 2/1 | - | - | - | - | ... | - | 10 | 2/15予定 | 090-ZZZZ
```

## 🔐 Google Sheet のセキュリティ設定

### 顧客用リンクの作成方法

```
1. Google Sheet を作成
2. 「フィルタ表示」で顧客別ビューを作成
3. 顧客用リンク（読み取り専用）を発行
4. 顧客にメール送信
```

### 権限設定

```
【スタッフ】
権限：編集（すべてのシートを編集可能）

【顧客】
権限：閲覧のみ（自分の行だけ見える設定）
```

## 💡 さらに便利にする工夫

### 工夫1：予約カレンダーと連動

```
Google Sheet で回数券管理
  ↓
同じ顧客の予約情報を記入
  ↓
予約日を Google Calendar に追加
  ↓
スタッフが予定を把握
```

### 工夫2：LINE 通知（オプション）

```
来店予定日の3日前に LINE で通知
「久保田様、3月1日ご予約ですね」

ユーザーが LINE Official Account を契約
  ↓
ユーザーが Google Sheet と連携
  ↓
自動通知（ユーザーが API 料金を負担）
```

### 工夫3：自動メール通知（オプション）

```
来店予定日の前日にメール
「明日がトリートメント予約日です」

ユーザーが Zapier（無料枠）を設定
  ↓
Google Sheet 更新 → メール自動送信
  ↓
完全自動化（ユーザー設定だけ）
```
