## ⏰ 実装の流れ（初回30分）

### Step 1：Google Sheet を作成（5分）

```
https://sheets.google.com にアクセス
  ↓
「新規」をクリック
  ↓
「スプレッドシート」を選択
  ↓
名前をつける：「回数券管理システム」
```

### Step 2：スタッフ用シートを作成（10分）

**シートの構成：**

```
【A列】顧客名
【B列】開始日
【C列】1回目来店日
【D列】1回目 ✓/空欄
【E列】2回目来店日
【F列】2回目 ✓/空欄
... 以下 10回目まで

【U列】残数（自動計算式）
【V列】次回予約日
【W列】連絡先
【X列】メモ
```

### シートのテンプレート

```
顧客名 | 開始日 | 1回予定日 | 1済 | 2回予定日 | 2済 | ... | 10回予定日 | 10済 | 残数 | 次回 | 電話 | メモ
------|--------|---------|-----|---------|-----|-----|---------|-----|------|------|-------|------
久保田寛 | 2026/1/1 | 1/15 | ✓ | 2/1 | ✓ | ... | 10/1 | | 8 | 3/1 | 090-1234 | 
田中太郎 | 2026/1/15 | 1/20 | ✓ | 2/5 | | ... | | | 9 | 2/5予定 | 090-5678 | 
```

### 残数の自動計算式（Excel 記法）

```
【U列の式】（例：U2 セル）
=10 - COUNTIF(D2:T2,"✓")

これで、✓ の個数を数えて、自動的に残数が計算されます
```

---

### Step 3：顧客用ビュー（フィルタ表示）を作成（10分）

Google Sheet の「フィルタ表示」機能を使う

```
1. スタッフ用シート作成後、
   「ビュー」→「フィルタ表示を作成」をクリック

2. 新しいフィルタ表示の名前：「顧客用ビュー」

3. フィルタ設定：
   ├─ 顧客別の行を表示する
   ├─ 必要な列だけ表示する
   └─ 編集不可（読み取り専用）にする
```

### 顧客用ビューに表示する情報

```
顧客名 | 開始日 | 1回目予定 | 1済 | 2回目予定 | 2済 | ... | 10回目予定 | 10済 | 残数 | 次回予約 | メモ
------|--------|---------|-----|---------|-----|-----|---------|-----|------|--------|------
久保田寛 | 2026/1/1 | 1/15 | ✓ | 2/1 | ✓ | ... | 10/1 | | 8 | 3/1 | 

（編集不可・読み取り専用）
```

### Step 4：アクセスリンクを生成（5分）

```
【スタッフ用リンク】
「共有」→ 編集権限を与える → リンクコピー
例：https://docs.google.com/spreadsheets/d/1a2b3c4d5e6f/edit

【顧客用リンク】（フィルタ表示）
「共有」→ 読み取り専用 → リンクコピー
例：https://docs.google.com/spreadsheets/d/1a2b3c4d5e6f/edit#gid=xxx
```
