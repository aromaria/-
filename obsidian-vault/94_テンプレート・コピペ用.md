### トリートメント回数券カレンダー（有料版）｜Mac自動連携

## 📅 トリートメント回数券カレンダーとは

このツールは、美容サロン・治療院の**回数券来店スケジュール**を**Macカレンダーに自動で表示**するツールです。

顧客の10回コースの来店予定日を入力するだけで、iCal形式のカレンダーファイルが自動生成。
Macカレンダーにインポートすれば、予約忘れがゼロになります。

## 🎯 こんな悩みを解決します

- 回数券の来店予定管理が手作業で大変
- 顧客が来店を忘れることがある
- 複数の顧客の予約を一括管理したい
- Macカレンダーと連携したい

## 📊 無料版 vs 有料版の比較

| 項目 | 無料版 | 有料版 |
|------|------|------|
| 基本機能（10回コース） | ✓ | ✓ |
| 複数顧客を同時管理 | ✗ | ✓ |
| 複数コース対応（5回・20回等） | ✗ | ✓ |
| PDF ガイド＆説明動画 | ✗ | ✓ |
| メールサポート | ✗ | ✓（月2回まで） |
| 使用期間 | 無期限 | 無期限 |
