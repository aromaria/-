## 2. メルマガ機能

### HTMLメール vs 文字メール
| 項目 | HTMLメール | 文字メール |
|---|---|---|
| 文字装飾 | ○ 可能 | × 不可 |
| 写真挿入 | ○ 可能 | × 不可 |
| 開封確認 | ○ 可能 | × 不可 |
| 携帯キャリア | × 非対応（2017年12月〜） | ○ 対応 |
| 古いメールソフト | △ 表示崩れの可能性 | ○ 問題なし |

**重要**: 2017年12月の仕様変更により、携帯キャリアのメールアドレス宛にはHTMLメールは送信されない。文字メールタブにも記入して併用が必須。

### 同時配信の方法
HTMLメールでメルマガを書く際に、「文字メールタブ」にも記入すれば、携帯アドレスの方とPCアドレスの方の両方に配信可能。

### テスト配信
- 「テスト配信」ボタンをクリック
- テスト配信は送信元メールアドレス宛に送られる
- 本番配信前に必ずテスト配信で確認すること

### 予約配信
- 配信予定日時を選択
- 「すぐに保存/配信の予約」をクリックで予約完了
- 予約後の修正・取消も管理画面から可能

### 読者登録
- メルマガの登録フォームから読者が自分で登録
- 登録完了メールのリンクをクリックして手続き完了（ダブルオプトイン）
- 手続き中断の場合: リンクをクリックできずに中断されるケースあり
- 管理者がメールアドレスを手動で登録することも可能

### 読者のアクセス足跡
- メルマガ読者からのアクセス足跡を確認する機能あり

### テンプレート変数（差し込み）
| 変数 | 内容 |
|---|---|
| `((customer_name))` | お客様のフルネーム |
| `((friendly_name))` | お客様の呼び名 |
| `((proposal_code))` | 提案コード |
| `((serial_code))` | シリアルコード |

### 配信に関するトラブルシューティング
- メールが届かない場合: 迷惑メールフォルダを確認
- @reservestock.jp ドメインの受信許可設定を案内
- リザストメーラーアプリを使うと文字化けなく確実に届く
- iPhoneでHTMLメールが読めない場合の対処法あり

## 3. ステップメール機能

### ステップメールとは
- あらかじめ設定したシナリオに沿って、登録後に自動で順番に配信されるメール
- メルマガとは異なり、いつ購読開始されるか分からない

### 配信済みメルマガからステップメールを作成
1. バックナンバー配信用のステップメールを作成
2. メルマガ記事一覧から追加したい記事を選択
3. 記事タイトルをクリック → 編集画面を開く
4. 「この記事をステップメールに追加」ボタンをクリック

### ステップメール作成時の注意
- 季節のあいさつは削除または修正する（いつ読まれるか分からないため）
- イベント募集リンクなど時限性のある内容も修正が必要
- バックナンバーを公開している場合、直近の配信記事が登録時に自動配信される仕様

## 4. メルマガ管理画面の構造

### 記事の状態（public_status）
| 状態 | 説明 |
|---|---|
| `private` | 非公開（下書き） |
| `public` | 公開（配信可能） |
| `backnumber` | バックナンバーとして公開 |

### 記事の操作フロー
1. 記事作成（private で保存）
2. 内容確認・テスト配信
3. 公開設定 → 配信予約 or 即時配信
4. 配信後 → バックナンバーとして公開（任意）
5. バックナンバー → ステップメールに追加（任意）

## 8. 岩本さんの運用に直結する知識

### 現在の運用状況
- メルマガ名: 「アロマリア美健康の秘訣」
- Bearer APIキー（rs_live_...）でAPI操作
- Claude Code でリライト → batch-save で非公開保存 → 管理画面で確認後に配信

### 実践的な活用ポイント
1. **ステップメール化**: リライト済みの良質な記事はステップメールに追加 → 新規読者に自動配信
2. **バックナンバー公開**: 過去の良記事をバックナンバーとして公開 → SEO効果＆新規読者獲得
3. **文字メール併用**: HTMLメルマガには必ず文字メールも用意（携帯キャリア対策）
4. **テスト配信の徹底**: リライト記事は配信前にテスト配信で表示確認
5. **読者登録フォーム**: about.html や client-voices.html にフォーム設置 → serialcd API で直接登録
