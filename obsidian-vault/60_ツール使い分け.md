# ツール使い分け（Claude・NotebookLM・Gemini・Obsidian・Drive）

> 迷ったらこのメモを見る。「どれを・いつ使うか」の地図。

## それぞれの得意（キャラで覚える）
| ツール | キャラ | 一番得意なこと |
|---|---|---|
| Claude | 🛠 職人・司令塔 | 考える・書く・直す・作る・整理する。複数手順の作業、ソフト改修、Obsidian整理。NotebookLMやDriveも呼べる |
| NotebookLM | 📚 資料に詳しい司書 | あなたの資料だけに忠実に答える。要約・出典つき回答・音声解説。ウソをつかない |
| Gemini | 🔍 Google世界の便利屋 | Gmail・Drive・Docs・カレンダー・Google検索と相性抜群。最新情報の検索、Google内の作業 |
| Obsidian | 📗 本棚 | ためる・見返す（AIではない・保管庫） |
| Google Drive | 🗄 書庫 | ファイルの保存場所 |

## いつ・どれを使う？
| やりたいこと | 使うのは |
|---|---|
| 資料の中身を正確に知りたい・要約したい | NotebookLM（出典つきで安心） |
| 文章を作る・直す／ソフトを改修／段取りを組む | Claude |
| 最新のニュース・一般情報を調べる | Gemini（Google検索が強い） |
| Gmailの整理、Googleドキュメント作成、予定調整 | Gemini |
| メモをためる・見返す | Obsidian |
| ファイルを保管する | Google Drive |

## 事務局の実例
- 電話申込ソフトを直したい → 🛠 Claude
- 「入金確認の手順どうだっけ？」 → 📚 NotebookLM（資料に聞く）
- 申込者へのメール文面を作る → 🔍 Gemini（Gmail連携）or 🛠 Claude（凝った文章）
- 決定事項を記録 → 📗 Obsidian（Claudeに「決定ログに追記して」）
- リザストの最新仕様を調べる → 🔍 Gemini（検索）

## ひとことルール
- 自分の資料 → NotebookLM
- 作る・直す → Claude
- Google関係・調べもの → Gemini
- ためる → Obsidian／Drive

## ⚠️ 大事：Claude は「Chat」側で使う（Code側では連携が使えない）
- Drive・NotebookLM・Gmail・カレンダー等を使うときは、必ずアプリ左上の **「💬 Chat」** に切り替える
- **「</> Code」側**（ソフト作成用）ではコネクタが使えない
- Google Drive は Chat 側で **「保存」も「呼び出し」も両方できる**（2026-07-07 確認済み）
- NotebookLM への質問も Chat 側で行う

## 接続メモ（技術）
- NotebookLM = Mac の Claude Desktop に「notebooklm」ローカルMCPで接続済み（21冊）
  - 再設定は Terminal で `nlm login`（認証）／設定は `~/Library/Application Support/Claude/claude_desktop_config.json`
- Google Drive・Gmail・カレンダー・GitHub・Canva = Claude Desktop の Webコネクタで接続済み
