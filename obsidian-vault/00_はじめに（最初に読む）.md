# はじめに — この保管庫（Vault）の使い方

これは **Obsidian（オブシディアン）** で開く「知識の保管庫」です。
中身は普通のテキスト（.md）なので、**Claude も直接 読み書きできます**。

## Obsidianで開く手順（Mac / Windows 共通）
1. Obsidian を起動 →「**Open folder as vault（フォルダーを保管庫として開く）**」
2. この `obsidian-vault` フォルダーを選ぶ
3. 左のファイル一覧から番号順に読めばOK

## なぜこれでトークンが減るの？
- Claude は毎回、大きなファイルを読み直して状況を思い出す → これがトークンを一番使う
- ここに **要点を小さく分けて** 置いておくと、Claude は必要な1枚だけ読めばよい
- さらに **NotebookLM に読み込ませれば、質問・要約は無料**（Claudeを使わない）

## 中身
| ファイル | 何が書いてある |
|---|---|
| 00_はじめに | このページ |
| 10_プロジェクト概要 | 何のソフトか・誰が使うか |
| 20_ソフトの使い方 | スタッフ向けの操作 |
| 30_技術メモ | URL・仕組み・安全ルール |
| 40_決定事項ログ | 「なぜこうしたか」の記録 |

## 3つのツールの役割分担
- **Obsidian** = 保管庫（ためる・見返す）
- **Claude** = 作る・整理する・直す
- **NotebookLM** = 資料に質問・要約・音声解説（無料でたくさん使える）
