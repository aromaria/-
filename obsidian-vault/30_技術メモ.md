## 仕組み（4人共有）
アプリ(index.html) → Apps Script Web App(/exec) → Driveフォルダ内スプレッドシート。
- 保存: doPost（https時）＋ doGet action=save（file://でPOSTが弾かれる対策）
- 読込: doGet を JSONP（`<script>`タグ）で取得
- 追記/更新は id 単位の upsert（Code.gs の upsertRecord_）
- Driveフォルダ FOLDER_ID = 1pFy2yPycE8hjoqVVtVm1bmN5OyhPGRkl
- 保存ファイル名 = 電話対応ソフト_申込データ

## 設定の場所（index.html 先頭付近）
- HANDLERS … 対応者名の配列
- STATUSES … ステータス一覧
- DEFAULT_CLOUD_URL … 既定の接続先（公開ページには空。設定リンクで注入）

## 安全ルール（厳守）
- APIトークンを画面・GitHubに出さない
- /exec URL は公開ページのソースに入れない（設定リンクで私的配布のみ）
- 本番送信・削除・公開は承認後のみ／mainへ直接反映しない
- Apps Scriptアクセス = 「全員（ログイン不要）」。「Googleアカウントを持つ全員」はSafariがcookie遮断で失敗

## 既知の小さな不具合
- シート人間可読列で携帯番号先頭0が欠落（JSON列は正常）。保留

## Apps Scriptの再デプロイ時
Code.gs を更新 → 「デプロイを管理」→ 既存デプロイを編集 → 新バージョン。URLは変わらない。
