# NotebookLM 自動質問応答システム

## 🎯 目的

購入者からの質問を **NotebookLM が自動回答** する仕組みを作る

あなたのメール対応負荷を **ほぼゼロ** にする

---

## 🔄 仕組み

### 【従来の方式】
```
購入者から質問メール
  ↓
あなたが読む・返信を書く
  ↓
購入者に返信
  ↓
あなたの時間：10分/件
```

### 【NotebookLM を使った新しい方式】
```
購入者が自分で質問する
  ↓
NotebookLM が FAQ から自動回答
  ↓
購入者は即座に答えを得る
  ↓
あなたの時間：ゼロ

複雑な質問だけあなたが対応：月 1～2 件
```

---

## 📋 実装手順

### Step 1：NotebookLM にアカウント登録（無料）

```
https://notebooklm.google.com
にアクセス

Google アカウントでログイン
```

### Step 2：ノートブックを作成

```
「新しいノートブック」をクリック
↓
「トリートメント回数券カレンダー - FAQ」という名前をつける
```

### Step 3：FAQ ドキュメントをアップロード

以下の内容を PDF または テキストで作成して、アップロードします：

```
【アップロード内容】

## トリートメント回数券カレンダー - よくある質問

### Q1: 無料版と有料版の違いは？
A: 無料版は1顧客分。有料版は複数顧客が管理できます。

### Q2: Googleカレンダーに対応していますか？
A: はい。iCal形式で出力されるため対応しています。

### Q3: 使い始めたら月額課金が発生しますか？
A: いいえ。有料版は8,800円の一度の購入で永久利用です。

### Q4: 返金はできますか？
A: デジタル商品のため返金不可です。無料版でお試しください。

### Q5: カスタマイズ対応はしていますか？
A: いいえ。本ツールはシンプルさが特徴のため対応していません。

### Q6: ファイルが開きません。
A: 以下をお試しください：
   1. ブラウザを最新版に更新
   2. キャッシュをクリア（Cmd+Shift+Delete）
   3. 別のブラウザで試す

### Q7: 複数コースに対応していますか？
A: 有料版では5回・10回・20回・30回に対応しています。

### Q8: サポートはありますか？
A: メールサポートは月2回までです。

### Q9: データはどこに保存されますか？
A: ローカルストレージに保存されます。サーバーには保存されません。

### Q10: Macカレンダー以外のカレンダーに対応していますか？
A: iCal形式で出力されるため、GoogleカレンダーやiPhoneカレンダーにも対応しています。

---

【使い方ガイド】
・顧客名を入力
・10回の来店予定日を入力
・「カレンダーを生成」をクリック
・「ダウンロード」をクリック
・ダウンロードしたファイルをMacカレンダーにドラッグ&ドロップ
・カレンダーに反映される
```

### Step 4：NotebookLM のリンクを取得

```
ノートブックを作成後、
「共有」ボタンをクリック
↓
「公開リンク」を取得
↓
このリンクをコピーして保存

例：https://notebooklm.google.com/notebook/abc123xyz
```

### Step 5：購入者にリンクを案内

note の販売ページに以下を追加：

```
【ご質問がある方へ】

ご購入ありがとうございます。
ご質問やご不明な点がある場合は、
以下の NotebookLM で質問してください。

AI が FAQ から自動で回答します：
→ https://notebooklm.google.com/notebook/abc123xyz

ご質問の内容に応じて、AI が関連する回答を提示します。

【対応】
・通常のご質問：NotebookLM が自動回答
・複雑なご質問：メールでお問い合わせください

メールアドレス：i.aromaria@gmail.com
（返信は月2回までとさせていただきます）
```

### Step 6：購入者向けメール自動返信に追加

```
【メール本文に追加】

---

【ご質問がある場合】

まずは NotebookLM で質問してください。
AI が FAQ から自動で答えを見つけます。

🤖 質問ページはこちら：
https://notebooklm.google.com/notebook/abc123xyz

※複雑なご質問の場合のみ、メールでお問い合わせください。
```

## 🎛️ NotebookLM の使い方（購入者向け説明）

### 購入者が質問するとき

```
1. NotebookLM のリンクを開く
   https://notebooklm.google.com/notebook/abc123xyz

2. 「新しいノート」をクリック

3. 質問を入力
   例：「無料版と有料版は何が違いますか？」

4. 送信すると、AI が FAQ から関連する回答を提示

5. わからないことがあれば、さらに詳しく聞くことも可能
```

### 例えば：

```
【購入者が質問】
「このツールは月額課金がありますか？」

【NotebookLM が自動回答】
「いいえ。有料版は8,800円の一度の購入で永久利用です。
月額課金はありません。」

【購入者が追加質問】
「では、使い続けるのに料金は発生しませんか？」

【NotebookLM が自動回答】
「正しいです。一度8,800円でご購入いただければ、
その後のランニング費用は発生しません。
月額課金ではなく、永久利用が可能です。」
```
