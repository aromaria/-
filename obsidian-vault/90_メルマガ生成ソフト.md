# メルマガ生成ソフト（アロマリア美健康の秘訣）

## これは何
リザストのメルマガ「アロマリア美健康の秘訣」の原稿を、AIが岩本純子先生の文体で自動生成するブラウザツール。

公開URL（mainマージ後）: `https://aromaria.github.io/-/newsletter.html`
ソースファイル: `newsletter.html`（リポジトリ直下）

## 主な機能
| 機能 | 内容 |
|---|---|
| AI提供元 | OpenAI / Anthropic / Gemini の3社対応（プロバイダー別にキー保存） |
| モデル選択 | 各社の推奨モデルをドロップダウンで選択 |
| Gemini自動フォールバック | クォータ超過時に別モデルへ自動切替 |
| テーマプリセット | メタトロン解析 / 自己治癒力 / スクール / 波動美健康 / 心身魂 / アロマ感情解放の6種 |
| ターゲットタグ | 8種のペルソナを複数組み合わせ可能 |
| CTA（行動喚起） | メタトロン予約 / スクール説明会 / 体験セッション / オリエンテーション / 全部の5種 |
| 薬機法チェック | 禁止表現を自動検出→AI修正→再チェックの3段構え |
| 件名生成 | 本文に最適化した5候補（全角18文字以内） |
| A/B/Cバリエーション | 最大3パターン一括生成で比較 |
| 季節自動検出 | 今の季節に合った養生キーワードを自動挿入 |
| リザスト最適化 | 1行35文字以内・1文改行・スマホ表示最適 |

## 対応モデル一覧
| 提供元 | モデル |
|---|---|
| OpenAI | GPT-4o（推奨）/ GPT-4o mini（軽量） |
| Anthropic | Claude Sonnet 4（推奨）/ Claude Haiku 4.5（軽量） |
| Gemini | 2.0 Flash（推奨）/ 1.5 Flash（安定版）/ 1.5 Pro（高性能） |

## 使い方
1. `newsletter.html` をブラウザで開く
2. AI提供元を選び、APIキーを入れる（プロバイダーごとに別々に保存可能）
3. テーマを選ぶ（またはカスタム入力）
4. ターゲット読者をタグで選ぶ
5. CTA・季節・バリエーション数を設定
6. 「生成」ボタン → 件名候補5つ＋本文が生成される
7. 「コピー」→ リザストに貼り付け

## 薬機法について
自動チェック機能があるが、最終確認は人間が必ず行う。
特に「特定の病名＋改善の直接結合」「断定表現」に注意。

## 心理テクニック（プロンプトに組み込み済み）
- 共感ファースト: 読者の悩みを「わかります」と受け止めてから本題へ
- ストーリー: 岩本純子先生自身の体験を物語として
- 好奇心ギャップ: 「実は…」で読み進めたくなる仕掛け
- 社会的証明: 「3,000名以上」を自然に
- 権威性: IFA認定・AEAJ認定校
- 希少性: 「少人数制」「お一人おひとりに合わせた」
