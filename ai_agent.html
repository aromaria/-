AI事務局エージェント

キー未設定

自分のAPIキーを入れると、この画面から直接AIに指示を出せます。キーはあなたのブラウザだけに保存され、送信先はAI提供元（OpenAI／Anthropic）のみです。

1 AIキーを取得する

初めての方向けの案内です。ボタンで切り替わります。（キーは各社の公式サイトで発行します）

OpenAI キー発行ページを開く ↗
  1. 黒いボタン + Create new secret key を押す
  2. そのまま Create secret key を押す
  3. 表示された鍵の右のコピーボタンを1回押す（鍵は二度と表示されないので必ずコピー）
  4. 下の「ステップ2」に貼り付け
コピーし忘れて閉じた時：一覧のゴミ箱マークで古い鍵を消し、もう一度作り直せばOK。

「quota」エラーが出たら、残高0の可能性。カードで最低$5だけ入金します。

  1. 左上の 🏠 Home → 右下の Add credits
  2. カード情報を入れ、$5 だけプリペイド購入
  3. 残高が $5.00 になったら、この画面に戻って再実行
Anthropic キー発行ページを開く ↗
  1. ログイン →「API Keys」→「Create Key」
  2. sk-ant-… をコピーして、ステップ2に貼り付け
  • 使った分だけの課金（月額固定なし）。短いメール下書きなら概ね1回 数円以内が目安（モデルにより変動）。
  • 安全：キーはこの端末のブラウザに保存。送信先はAI提供元のみで、販売者や第三者には送りません。共有PCでは使用後に「キーを消す」を押してください。
