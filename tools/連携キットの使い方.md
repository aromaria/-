# 3システム連携キットの使い方（新しい業務に横展開する）

このツールで、**新しい業務ごとに「Claude ＋ Obsidian ＋ NotebookLM」の同じ仕組み**を一発で作れます。

## いちばんかんたんな使い方（あなたがやること）
Claudeに、こう頼むだけ 👇

> **「新しい業務『◯◯◯』の連携キットを作って。
> 内容は △△△。関係者は 玉川・岩本。要点は □□□。」**

すると Claude が中で生成ツールを動かし、次の3点をお渡しします：
1. **`◯◯◯_obsidian-vault.zip`** … Obsidianで「Open folder as vault」で開く
2. **`◯◯◯_NotebookLM資料.pdf`** … NotebookLMにアップロード（文字化けなし）
3. 必要なら中身の説明

あとは今回と同じ手順（Obsidianで開く／NotebookLMにPDFを入れる）で完了です。

---

## 中で動いているコマンド（Claude用メモ）
```
python3 tools/連携キット生成.py \
  --name "業務名" \
  --desc "一言説明" \
  --members "玉川,岩本,藤本,田尻" \
  --facts "要点1／要点2／要点3" \
  --url "https://…" \
  --out out
```
- `out/<業務名>/` に CLAUDE.md・obsidian-vault・notebooklm 一式
- `out/<業務名>_obsidian-vault.zip` と `out/<業務名>_NotebookLM資料.pdf`
- reportlab が無い環境では PDF はスキップ（`pip install reportlab` で有効化）

## 生成されるひな型の中身
- `CLAUDE.md` … Claudeが最初に読む要点の地図（トークン節約の本体）
- `obsidian-vault/00〜50` … はじめに／概要／進め方／メモ／決定ログ／連携ガイド
- `notebooklm/資料まとめ.md` … NotebookLM投入用の総合資料

## 運用のコツ
- 迷ったら「原本はGitHub」。Obsidian・NotebookLMはコピー。
- Claudeには「CLAUDE.md と 該当メモだけ見て」と範囲を絞るとトークン節約。
- 業務が増えたら、この手順を繰り返すだけで横展開できる。
