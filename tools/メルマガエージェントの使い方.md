# メルマガ生成エージェント v2 — 使い方

## 旧版からの改善点

| 項目 | 旧版 | v2 |
|------|------|-----|
| 薬機法チェック | なし | 自動検出＋自動修正＋再チェック |
| 件名生成 | なし | 本文に最適化した5候補を自動生成 |
| 出力の安定性 | 毎回長さ・構成がバラバラ | 構成テンプレート＋文字数制御 |
| A/Bテスト | 不可 | 最大3バリエーション一括生成 |
| エラー耐性 | クラッシュ | 指数バックオフで3回リトライ |
| リザスト最適化 | なし | 1行35文字・改行ルール・CTA導線 |
| 使いやすさ | コード編集が必要 | CLI引数 or 対話モード |

## セットアップ

```bash
pip install openai
export OPENAI_API_KEY="sk-..."
```

## 使い方

### 1. 対話モード（おすすめ）

```bash
python3 tools/newsletter_agent.py --interactive
```

テーマとターゲットをメニューから選ぶか、自由入力できます。

### 2. コマンドライン

```bash
# 基本
python3 tools/newsletter_agent.py \
  --theme "細胞が本来持っている自己治癒力を目覚めさせるセルフケア" \
  --target "原因不明の体調不良が続き、薬を増やしたくない方"

# 3パターン生成してファイルに保存
python3 tools/newsletter_agent.py \
  --theme "アロマで心身を整える" \
  --target "ストレスで眠れない方" \
  --variations 3 \
  --output newsletter_draft.txt
```

## 出力内容

1. **件名候補 5つ** — 開封率を意識した20文字以内
2. **メルマガ本文** — 約1,800文字（リザスト最適長）
3. **薬機法チェック結果** — 通過 or 手動確認が必要な箇所

## 薬機法コンプライアンスについて

自動チェック機能がありますが、最終的な判断は人間が行ってください。
特に以下の表現が含まれていないか確認をお願いします：

- 特定の病名＋改善を直接結びつける表現
- 「治る」「完治」等の断定的な医療効果の表現
- 「必ず」「100%」等の保証表現
