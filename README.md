# リザスト電話申込 入力サポート（第1段階・ローカル版）

連続講演会（全5回）の電話申込を、事務局スタッフが聞き取りながら入力し、
内容を確認したうえで **リザスト申込画面へ手入力** するための補助ソフトです。

## 使い方

1. `index.html` をブラウザで開くだけで動きます（PC・スマホ対応）。
   - インストール・サーバー・ビルド不要。
2. 画面上部で **対応者** を選びます。
3. 「新規入力」タブで聞き取り内容を入力します。
4. 「入力チェック → 転記画面へ」を押すと、入力もれ・二重登録を確認できます。
5. 「リザスト転記」タブで、リザスト申込画面の項目順に並んだ内容を見ながら
   **手入力**します（各項目の「コピー」ボタンでクリップボードに取れます）。
6. 「この内容で保存」で端末内に記録され、「対応一覧」で管理できます。

## この段階でできること（第1段階：手入力サポート型）

- 電話申込者情報／参加者氏名（姓・名）／ふりがな（せい・めい）
- メールアドレス（確認入力つき）／携帯電話番号／領収書宛名
- 参加回（第1〜5回・全5回、複数選択可／「全5回」で自動チェック）
- 参加方法（会場7,000／Zoom4,000／アーカイブ2,000）
- 支払い方法（銀行振込／PayPal／その他）／振込予定日／備考
- リザスト転記用まとめ画面（項目コピー機能つき）
- 対応一覧では対応者・ステータスをその場で変更（即保存）
- 入力もれチェック／二重登録チェック
- 対応ステータス管理（12種：未対応〜要確認。①振込先伝達・入金予定日確認済み／②入金予定日を田尻さんへ連絡済み／③ソフトに記入・保存済み を含む）／対応者名の記録
- 対応一覧・検索・編集・複製・JSON書き出し

## 保存について

- 既定では、データは **この端末のブラウザ内（localStorage）** に保存されます。
- **クラウド保存（任意）**：Google Apps Script の「送信先URL」を設定すると、
  Drive フォルダ内の共有スプレッドシートにも保存され、4人で共有できます。
  - 設定方法：`apps_script/SETUP.md`
  - 受け皿のコード：`apps_script/Code.gs`
  - アプリに設定するのは「送信先URL」だけで、**APIトークンは使いません**。
  - URL未設定のときは、これまでどおり端末内だけに保存されます（送信は一切行われません）。

## 安全に関する約束（重要）

- リザストへ **自動送信しません**（本番API送信なし）。
- APIトークンは **画面・コード・Git のいずれにも含めません**。
- 元データは上書き削除せず、キャンセルは「ステータス」で論理管理します。
- 開発は作業用ブランチのみで行い、`main` へ直接反映しません。
- 削除・公開・外部送信は、依頼者の明確な承認後のみ行います。
