事務局アシスタント 連携ガイド

NotebookLM・Claude・Obsidian・Google Drive をつないだ環境の「できること」と「手順の記録」。

📚 NotebookLM（21冊） 🛠 Claude 📗 Obsidian（自動同期） 🗄 Google Drive ✉️ Gmail ／ 📅 カレンダー
01

役割分担（迷ったらこれ）

「自分の資料→NotebookLM／作る・直す→Claude／Google関係→Drive・Gmail／ためる→Obsidian」

📚 資料の司書

NotebookLM

自分の資料だけに忠実に回答・要約・出典つき。ウソをつかない。

🛠 職人・司令塔

Claude

作る・直す・整理する。Drive/Gmail/NotebookLMも呼べる。

📗 本棚

Obsidian

ためる・見返す。GitHubと自動同期（何もしなくても最新）。

🗄 書庫

Google Drive

ファイルの保存・呼び出し。Chat側で保存も読み込みも可能。

02

できることリスト

Claude Desktop の Chat側 に貼るだけ。各行の「コピー」を押して使ってください。

03

セットアップの記録（振り返り）

再設定やトラブル時の参照用。普段は読まなくてOK。

  1. NotebookLM をClaudeにつなぐ：ターミナルで uv tool install notebooklm-mcp-cli →（OpenSSL等が要る場合 brew install openssl@3 pkg-config rust）→ nlm login（Googleログイン）。
  2. Claude Desktop に登録：~/Library/Application Support/Claude/claude_desktop_config.json に notebooklm を追記 → Claude Desktop を再起動 → コネクタに「notebooklm」が✓。
  3. Google Drive など：Claude Desktop の「コネクタ」で接続済み（Chat側で使う）。
  4. Obsidian 自動同期：git clone https://github.com/aromaria/-.git ~/超古代PJ-Vault → そのフォルダをVaultで開く → コミュニティプラグイン「Git（Vinzent）」→ Auto pull=10／Pull on startup=ON／Push on commit-and-sync=OFF。
04

使い分け早見表

やりたいこと使うもの
資料の中身を正確に知る・要約NotebookLM（Chat側）
文章を作る・直す／ソフト改修Claude
ファイルの保存・呼び出しGoogle Drive（Chat側）
メール整理・下書き／予定登録Gmail・カレンダー（Chat側）
メモをためる・見返すObsidian（超古代PJ-Vault）
最新ニュース・一般情報を調べるGemini（gemini.google.com・Web版）
05

困ったとき

Drive/NotebookLMが使えない → 左上を 💬 Chat に切り替える（</> Code側では使えません）。
Obsidianで違う保管庫が開いた → 左下の ⇅ から 超古代PJ-Vault に切り替える。
最新メモが来ない → Obsidianを開き直す（起動時に自動プル）。または画面右下の同期マークから更新。
NotebookLMの接続が切れた → ターミナルで nlm login を実行し直す。
Gemini を使いたい → gemini.google.com（Web版）を開くだけ。Google Drive/Gmailに元から対応。※個人向けの Gemini CLI ログインは Google が終了（Antigravityへ移行）したため、CLIは使いません。
